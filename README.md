# Suran.QQ

接 QQ 开放平台的官方机器人：自己取 access_token 并续期、连 WebSocket 网关收事件、把 QQ 侧消息按会话形状注入 Alife，回信由模型调用本插件的工具发出。

## 功能

- 发消息：文本、markdown、ARK 卡片、富媒体（图片 / 视频 / 文件 / 语音）
- 流式分段输出、输入中提示、撤回、按钮回调查询与应答
- 群资料、成员列表与详情、单人禁言、全员禁言、踢人
- 加群申请查询与审批、审批策略增删改查、审批白名单
- 群黑名单查询与操作
- 频道：我的频道、子频道列表与创建 / 修改、频道成员
- 菜单与面板：菜单查询 / 设置、面板创建 / 信息 / 目标 / 修改
- 身份展示与绑定、生成分享链接、找人、markdown 图片上传与删除
- 环境自检：检查配置与连通性
